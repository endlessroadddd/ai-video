# Discord UI Clone Template

This template is a reusable React + CSS port of the Discord UI clone reference used for scene-first short-asset work.

Reference sources used for this template:

- `C:\Users\ASUS\Downloads\index.html`
- `sw3do/discord-ui-clone`

## Intended use

- Reuse this when a short asset needs a realistic Discord-like community or chat surface
- Use it as the first built screen in the script-first lane when the user wants to approve the interface before motion work continues
- Replace only the channel labels, messages, and focused proof element first
- Keep the structural DOM and CSS close to the reference before applying scene-specific copy

## Included stack

- Vite
- React
- TypeScript
- plain CSS

## Notes

- The template keeps the original Discord-like structure and styling as the baseline
- It loads Inter and Font Awesome from CDNs in `index.html` for visual fidelity
- If later work must be fully offline, replace the external icon and font links with local assets before delivery
