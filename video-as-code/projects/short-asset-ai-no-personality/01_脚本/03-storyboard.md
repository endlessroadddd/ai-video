# Storyboard｜短视频 01：AI 没有人格

> 创作日期：2026-04-07

---

## Scene 01｜字幕开场（0–4s）

**构图**：全黑底，居中两行字，第一行先显，第二行延迟 1.5s 出现

**视觉焦点**：文字本身

**文字**：
```
有些社群，把 AI 放进去之后
用户开始消失
```

**字体**：Recoleta / 白色 / 居中 / 约 64px

**动效**：opacity 淡入，无需其他效果

**镜头类型**：C 类

---

## Scene 02｜世界建立（4–14s）

**构图**：Discord 深色界面全屏填充，1920×1080

```
┌────────────────────────────────────────────────────┐
│  服务器图标栏  │  频道列表  │  聊天区域  │  成员列表  │
│  (72px)       │  (240px)   │  (主体)    │  (240px)  │
└────────────────────────────────────────────────────┘
```

**内容细节**：
- 服务器图标：【待补充】幻想/二次元风格 icon（圆角方形）
- 频道列表：5 条频道，当前高亮 `⚔️ 今日任务`
- 聊天区：按顺序逐条出现，时间戳模拟真实间隔
- 成员列表：显示 `在线 · 248`，头像用 DiscordAvatar 组件生成

**关键感受**：活跃、热闹、玩家社群的人情味

**动效**：消息逐条出现（每条间隔约 0.8–1.2s），模拟真实打字节奏

**镜头类型**：C 类（纯代码，组件库驱动）

**待补充素材**：服务器图标（幻想公会风格）

---

## Scene 03｜事件（14–26s）

**构图**：同上，但视线引导到聊天区中下部

**关键视觉处理**：
1. `luna_guild` 发出消息后，停顿明显拉长（约 1.5s），制造悬念
2. AI 回复气泡出现时，整个气泡区域外框轻微高亮（淡黄或淡红描边），标注"异物"感
3. AI 头像：机器人图标（Discord 蓝 `#5865f2`，使用 `robotPreset`）
4. AI 的名字：**会长**（与人类用户一样的昵称，故意混淆，但头像是机器人）

**关键感受**：气氛骤然从热闹切换到"什么情况"

**动效**：AI 气泡入场时可以有轻微 scale-in（0.95→1.0），强调"这个东西不一样"

**镜头类型**：C 类

---

## Scene 04｜反应（26–32s）

**构图**：继续聊天区，快节奏出现几条短回复

**视觉重点**：
- 反应消息节奏比 Scene 02 更快（每条 0.5–0.7s）
- 最后一条消息后，光标闪动，无新消息——静止感强烈

**文字要出现这个对比**：
- 用户的消息：有昵称、有人情、有角色感
- AI 的回复：正式、无昵称匹配、像客服

**镜头类型**：C 类

---

## Scene 05｜流失（32–42s）

**构图**：两种视觉选择（待定，建议 A）

**选项 A（推荐）：成员列表 + 退出通知流**
```
聊天区主体渐暗（opacity 降至 30%）
右侧成员列表区域作为视觉中心
"X 离开了服务器" 系统消息从底部快速滚上来
右上角在线人数计数器缓慢下跌
```

**选项 B：折线图**
```
切换到一张折线图（代码绘制）
X 轴：时间（周）
Y 轴：活跃用户数
曲线从高点急速下滑
图表上方一行字："AI 接入后第 3 周"
```

**关键感受**：量感要够大，不是 1-2 个人走，是一批人走

**待确认**：用 A 还是 B？或者 A→B 都做？

**镜头类型**：C 类
