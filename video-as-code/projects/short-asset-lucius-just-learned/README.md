# short-asset-lucius-just-learned Remotion 工程

这是 `Lucius Just Learned` 的正式 Remotion 工程入口目录。

## Composition

- ID：`LuciusJustLearned`
- 分辨率：`2560x1440`
- 帧率：`60fps`
- 时长：`540 frames / 9.00 sec`

## 时间点

- `0.6s`：`29%` 起点出现。
- `1.15s - 5.05s`：主曲线从左向右生长。
- `5.0s`：`88%` 终点和柔光出现。
- `6.0s`：`NO prompts` 出现。
- `6.12s`：`NO fine-tuning` 出现。
- `7.0s`：`Lucius just learned.` 出现。

## 命令

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run still
npm.cmd run render
```
