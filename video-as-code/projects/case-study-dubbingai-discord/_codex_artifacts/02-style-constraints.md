# Style Constraints

## Typography
- Use `SF Pro` or close system fallback for labels, UI text, metrics, and explanatory copy.
- Use `Recoleta` or close editorial serif fallback only for key headlines, brand moments, and the final principle scene.
- Keep the serif moments rare so they read as intentional emphasis, not full-page styling.

## Palette
- `Lucius Purple #5538C7`
- `Lavender Mist #BAB2FF`
- `Orchid Bloom #B268D8`
- `Deep Moss #1B4038`
- `Warm Ivory #E1DAC0`

## Contrast Rules
- Maintain strong foreground/background contrast.
- Avoid muddy low-contrast surfaces.
- Use ivory and soft white as the dominant field, with purple/moss as signal colors.

## Visual Language
- Simplified geometric forms.
- Soft rounded corners.
- Clean strokes.
- Warm but tech-forward surfaces.
- Halftone or dot-grid texture should stay subtle and structural.

## Composition Rules
- One primary reading path per scene.
- No gratuitous clutter.
- Do not stack multiple competing focal points.
- Use generous negative space and card spacing.

## Motion Rules
- Calm, deliberate, readable.
- No generic HUD clutter.
- No unnecessary overlap between scenes.
- No abrupt pop-in unless storyboarded.
- No flicker or blank flash frames.
- No exaggerated "AI magic" beams, sweeps, or glow effects.

## Asset Treatment
- Preserve clear space around the Lucius logo.
- No stretching, shadows, outlines, or low-contrast placement for logos.
- Discord and Lucius icons should feel integrated into the same system, not pasted on.

## Implementation Note
- Recoleta is not bundled as a local font asset in this project, so the code uses a close serif fallback stack while preserving the role split between system sans and editorial serif.
