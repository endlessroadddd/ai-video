# case-study-dubbingai-discord

Standalone case-study animation for the Lucius x DubbingAI Discord support story.

## Run

```bash
npm run preview
```

Then open:

`http://127.0.0.1:3006`

If you are running from the workspace root with a package manager that supports workspaces, you can also target the package by name.

## Project Shape

- `src/data/` case-study facts and scene timing
- `src/components/` reusable markup helpers
- `src/scenes/` scene composition
- `src/styles/` full visual system and motion
- `_codex_artifacts/` brief, storyboard, copy, and QA notes
