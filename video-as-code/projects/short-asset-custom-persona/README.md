# short-asset-custom-persona

Lucius short-form concept piece showing how a brand AI becomes a community-native persona called LUCI.

Uses Noto Emoji Animation assets (CC BY 4.0) for selected local animated emoji in B4.

## Views

- `?scene=b1|b2|b3|b4|b5`
- `?mode=static|motion`
- `?view=timeline`

## Run

```bash
npm install
npm run dev
```
