# Lucius Brand Guidelines

## 1. Logo Design Philosophy

### Core Symbol
- Use the icon from (`public/logo-mark-black.svg`) with the text 'Lucius'.

## 2. Color Usage Rules

### 2.1 Primary Colors and Usage Scenarios
- **Lucius Purple** (`#5538C7`): The sole primary color. Used for core brand elements, primary buttons, and key icons.
- **Warm Ivory** (`#E1DAC0`): Used for large background areas to create a warm tone.
- **Lavender Mist** (`#BAB2FF`), **Orchid Bloom** (`#B268D8`): Accent colors, used only for emphasis or marketing highlights.

### 2.2 Dark and Functional Colors
- **Deep Moss** (`#1B4038`): Used only for dark backgrounds or emphasis text.
- **Cobalt Pulse** (`#504DDC`): Used only in tech-focused scenarios, such as data visualization or code blocks.
- Functional areas (customer service, community, sales) may use different accent colors for differentiation, but overall saturation must coordinate with the primary color.

### 2.3 Color Contrast Requirements
- Body text contrast with background ≥ 4.5:1.
- Headlines (≥18pt) contrast ≥ 3:1.
- Do not use low-contrast text in the same color family on a primary color background.

---

## 3. Typography Usage Rules

### 3.1 Primary Font
- **SF Pro**: Used for all product interfaces, body text, descriptive copy, and system messages.
- Fallback fonts: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial`.

### 3.2 Secondary Font
- **Recoleta**: Used only for brand headlines (H1, H2), large promotional text, and special brand moments.
- Recoleta must not be used for body text, buttons, or small text sizes (<16px).

### 3.3 Font Size and Hierarchy
- Body text size ≥ 14px (mobile) or 16px (desktop).
- Line height should be at least 1.4 times the font size.
---

## 4. Key Usage Specifications

### Brand Personality Constraints
All AI outputs (copywriting, visuals, interaction descriptions) must embody the following keywords:
- Intelligent, Collaborative, Quietly Confident.

### Logo Clear Space
- Minimum clear space around the logo = the height of the logo icon.
- No other graphics, text, or UI elements may be placed within this area.

### Logo Don'ts
- Do not add shadows to the logo
- Do not add outlines/strokes to the logo
- Do not stretch or distort the logo
- Do not use low-resolution versions of the logo
- Do not change the logo's typography
- Do not place the logo on low-contrast backgrounds

*These guidelines are the core principles for Lucius brand visual identity. All related designs must strictly adhere to them.*
