# Case Study

## Core claim

Lucius can serve with the warmth and specificity of a real teammate, and users stay in-channel long enough to mistake it for a human agent.

## Asset direction

Build this asset as a social-first motion clip, not a page and not a literal product screenshot.

The story should be carried by two half-screen phones facing each other:

- left phone = `Lucius`
- right phone = `User`

The audience should feel like they are watching a live exchange unfold between two sides of the same support thread.

## Narrative proof path

1. The user asks a product-origin question in a real support context.
2. Lucius answers with human-feeling language that sounds like a teammate.
3. The user assumes they are speaking to a real support person and asks for a name to pass along praise.
4. Lucius reveals that it is Lucius, not a human agent.
5. The user responds with a short `Wow.`
6. The scene resolves with explicit proof that no human handoff was needed.

## What this asset is really proving

- Lucius does not sound stiff or templated.
- Lucius can hold a natural support exchange long enough to be mistaken for a person.
- The thread stays in-channel instead of escalating to a transfer.

## Non-goals

- no Discord recreation
- no landing page composition
- no dashboard-style proof bar
- no literal employee ID or tipping language
- no negative before/after comparison setup
