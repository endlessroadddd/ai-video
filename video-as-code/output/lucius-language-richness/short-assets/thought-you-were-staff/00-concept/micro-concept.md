# Micro Concept

## Core takeaway

Lucius can sound human enough to be mistaken for a teammate, and the conversation never needs a human handoff.

## Asset form

- social-first short animation
- full-bleed Lucius stage
- two half-screen phone frames
- silent-first and loopable
- reveal-led narrative

## Visual thesis

Build this as `Dual-Phone Reveal`: two devices face each other, messages type and send in rhythm, then the user realizes Lucius is not a human agent as the right phone gets pushed away and the Lucius device takes over the frame.

## Story beats

1. The user asks why the product was built.
2. Lucius answers like a teammate.
3. The user asks for a name to praise the service.
4. Lucius reveals itself.
5. The user replies `Wow.`
6. The Lucius device resolves into the brand end card.

## Guardrails

- no landing page grammar
- no full chat page
- no dashboard proof module
- no literal tipping copy
- no overblown sci-fi motion
