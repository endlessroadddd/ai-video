# Product Context

Lucius is an AI teammate for product communities and support surfaces.

In this repository, the product is framed as a system that:

- learns from actual community behavior
- handles repetitive support work
- keeps support coverage running
- escalates the edge cases that still need a human
- improves the operating model rather than only speeding up replies

For this case study, the output should explain Lucius as part of a real support workflow inside Discord, not as a floating AI abstraction.
