# Case Study

Customer: DubbingAI

Surface: Discord support community

Key public proof points:

- 30K members
- 80% automation in 15 days
- 3 -> 0 human mods
- 24/7 coverage
- "Lucius basically gave me my holidays back."

Core situation:

- support volume scaled faster than the team
- repeated questions kept returning
- human moderators kept absorbing escalation work
- the operational problem was repetition, not growth by itself

Desired explanation:

- show Lucius learning from real community behavior
- show Lucius turning repeated questions into structure
- show Lucius improving over time while escalating the edge cases that still need a human
- end on the broader principle, not a CTA
