# Design Guideline

Use the Lucius brand guideline as the baseline visual system.

Key expectations for this case:

- strict adherence to the provided Lucius color and typography roles
- warm but tech-forward surfaces
- deliberate, readable motion
- no flashy AI magic effects
- no unnecessary overlap or clutter
- minimal but premium composition

The output may make small, professional refinements in spacing, rhythm, and choreography, but must not drift from the established Lucius visual family.
