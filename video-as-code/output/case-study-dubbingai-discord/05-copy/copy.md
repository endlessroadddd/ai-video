### Scene 4 - Learning Loop

**Headline:** Lucius keeps improving.

**Subhead:** Four-step learning system

**Loop card titles and bodies:**

1. **Onboard from history**
   Start from the community's own chat history, repeated intents, and prior resolutions.

2. **Learn in the flow**
   Pick up new questions as they appear in live Discord support work.

3. **Optimize over time**
   Use successful resolutions and missed cases to improve future responses.

4. **Escalate edge cases**
   Hand off what still needs a human, then learn from the outcome.
