# Design Guideline

Use the Lucius brand system as the governing design reference, but apply it carefully for a problem-resonance asset.

Specific guidance for this asset:

- the "traditional AI assistant" surface must not look like Lucius
- the empty-comfort replies should feel polished but unhelpful
- the payment failure proof shot must be the strongest information beat in the sequence
- this is a silent-first asset, so every on-screen line must be readable in one pass
- motion should stay calm and legible, not flashy
- if Lucius branding appears at all, it should be restrained and only appear as a minimal closing tag
