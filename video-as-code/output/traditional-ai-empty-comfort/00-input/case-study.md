# Case Study Seed

Traditional AI assistant style "I am here to hold you steady" support feels emotionally soft but operationally empty.

User flow:

1. The user asks in a community channel why payment keeps failing after three days.
2. The assistant replies with comfort language but gives no useful action.
3. The user pushes back and asks for an actual solution.
4. The assistant claims the issue is solved.
5. The user returns to the product UI and payment is still stuck.

The asset should make the failure obvious from the user's point of view.
