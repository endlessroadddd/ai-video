# Product Context

Lucius should be understood as an AI teammate that actually helps the team move work forward, not as a passive assistant that only acknowledges user emotion.

For this short asset, the context baseline is:

- users ask for help inside real support and community surfaces
- the user cares about resolution, not soft reassurance by itself
- payment friction is a high-stakes support moment because it directly blocks revenue and intent
- empty empathy without action should feel like a failure mode
- the asset should set up why "AI teammate" matters by showing what the old assistant pattern gets wrong

Relevant Lucius positioning anchors:

- Lucius is an AI teammate for customer success and community operations
- Lucius should not read like a generic chatbot or simple autoresponder
- Lucius should be associated with operational follow-through, not decorative comfort
