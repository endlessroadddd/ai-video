# Scene QA Rules

These rules apply to the heavy lane.
Short assets use `rules/quality/asset-qa-rules.md`.

Every completed scene must be checked against these rules before the next scene begins.

## Visual clarity

- No unnecessary overlap between major information blocks.
- Core focal path is obvious within the first read.
- Typography remains readable at the target frame size.

## Design fidelity

- Scene follows the approved design guideline and style constraints.
- No accidental drift in palette, spacing rhythm, or type system.
- Reused assets/templates are modified only within the approved editable areas.
- Scene follows `rules/design/lucius-brand-application-rules.md` when Lucius branding is in scope.
- If the Lucius logo appears, it uses an approved variant, preserves clear space, and avoids forbidden treatments.
- Typography role split is preserved: SF Pro for interfaces and functional content, Recoleta for selective brand emphasis only.
- Off-palette accent colors, noisy icon styles, and overbearing halftone textures are treated as brand failures.

## Motion quality

- Motion is smooth and intentional.
- No flicker, accidental blank flashes, or popping layers unless storyboarded.
- Motion reinforces the scene goal instead of competing with it.
- Motion preserves the Lucius tone of quiet confidence rather than visual theatrics.

## Storyboard fidelity

- Static states match the approved storyboard.
- Motion steps and timing are recognizably faithful to the storyboard.
- Copy placement matches approved copy slots.
