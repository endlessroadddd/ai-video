# AI 商业视频前期策划

把产品事实转成观众看得懂、记得住、愿意采取行动的画面。适用于创意简报、剧本和内容系列规划。本文只指导前期编导判断；具体生图、视频生成、配音、剪辑和代码动画的操作方法，需要另行确定。

## 工作原则

- 先理解产品，再提出画面。优先亲自试用或检查真实界面，并阅读用户提供的资料、官网和产品文档。把已核实的功能、用户主张与待确认的说法分开；不能访问产品时，不得声称已经试用。
- 让 AI 整理资料、盘点素材、提出备选和协助执行。创意是否贴合产品、叙事是否清楚、品牌是否准确，始终需要判断和修改。
- 尊重用户已指定的片型、平台、时长和品牌要求。资料不足时，先完成能完成的部分，只追问会改变核心方向的信息。
- 不把某个模型或工具列为必需品。根据画面任务和可用资源选工具。

## 1. 建立产品简报

在写剧本前，弄清六项信息：

1. 产品是什么，实际能做什么；核心功能有哪些证据或演示。
2. 谁最需要它，在什么具体情境中需要。
3. 目标观众已经知道什么、还不懂什么、担心什么。
4. 视频发布在哪里，希望观众看完采取什么行动。
5. 哪些真实界面、操作、结果可以展示。
6. 可用的标志、字体、颜色、角色、图片和现有视频素材。

观众不认识产品时，先说明用途和价值；观众已经熟悉产品时，可以把更多篇幅用于品牌故事或态度。不要仅凭品牌大小推断观众认知，要结合目标受众和发布场景判断。

## 2. 按传播任务选择片型

| 片型 | 优先解决的问题 | 常见场景 |
| --- | --- | --- |
| 品牌形象片 | 传达品牌态度和故事 | 品牌传播、活动 |
| 长篇产品宣传片 | 解释定位及多个核心功能 | 新品发布、官网 |
| 场景短片 | 用一个情境讲清一个卖点 | 社媒、广告投放 |
| Motion 功能动画 | 准确展示操作、流程或原理 | 功能上线、演示 |
| 口播或种草片 | 通过讲述者介绍使用理由 | 短视频、广告投放 |
| 客户案例片 | 展示真实用户的使用变化 | 官网、销售沟通 |
| 教程片 | 教用户完成具体操作 | 产品引导、帮助中心 |

选片型时说明选择理由：观众的认知、要传达的信息量、发布渠道、可用素材，以及画面需要表达情绪还是准确展示界面。不要把一种片型当成所有需求的默认答案。

## 3. 构思剧本

### 长篇产品宣传片

- 先写一句核心信息：**谁，在什么情境下，因为产品得到什么结果**。
- 再找贯穿全片的创意概念，例如角色、场景规则、视觉隐喻或故事线。优先从产品本身的功能和定位生长出来，不为新奇而硬套。
- 将功能转成可见的行动及结果，并确认这些画面合起来能准确解释产品。抽象软件可用角色、光标或界面动作表示其工作，但不能让拟人化掩盖真实能力边界。

### 场景短片

- 一条片子聚焦一个卖点。开头尽快给出值得继续看的问题、痛点、反差或结果。
- 让卖点通过具体动作、变化或对比出现，避免只靠旁白说“高效”“可信”等形容词。
- 用有因果的场景推进：问题出现 → 产品发挥作用 → 观众看到结果 → 品牌与行动指引。时长和节奏按平台与任务调整，不把固定秒数当成保证效果的公式。

### Motion 功能动画

- 适合真实界面、操作步骤、数据流和抽象原理。优先使用准确的界面组件、截图或录屏；产品改版后同步核对画面。
- 功能演示可按“问题 → 解决方式 → 操作 → 结果 → 下一步”组织。画面出现的时机应与旁白、字幕和音乐相配合。
- 需要人物情绪和生活场景时，可与实拍或 AI 视频结合；界面特写、标注、字幕和品牌收尾可由动画承担。

## 4. 规划可复用内容

如果要连续发布，为角色、视觉风格、品牌字卡和常用场景建立一致的规则。让后续视频延续观众已认识的元素，同时围绕新功能、新情境或新问题展开；复用资产时仍要核对当前产品事实。

## 5. 交付与检查

按用户所需的详细程度交付创意简报、片型建议、剧本或系列规划。通常应能看见：目标观众与认知、核心信息、片型及理由、主要画面和因果、真实界面的使用方式、品牌呈现、结尾行动，以及待确认事实。可以提供不同创意方案，但要说明各自适用条件并给出明确建议。

制作中和交付前检查：

- 能否用一句话说清这条片子讲什么？开头是否让目标观众愿意继续看？
- 静音时是否仍能看懂主要变化？镜头之间是否有清楚的因果？
- 产品功能、界面、角色、字体和颜色是否准确？
- 结尾是否让观众知道下一步做什么？封面是否能准确吸引目标观众？
