# 视频项目初始化模板

> 用于在客户目录下新建长视频或短视频项目。

## 项目命名

### 长视频

```text
long-video-<topic>[_<variant>]
```

### 短视频

```text
short-asset-<topic>[_<variant>]
```

示例：

```text
long-video-lucius-overview
short-asset-golden-case-support_dc
```

## 标准目录

```text
<project-slug>/
├── README.md
├── PROGRESS.md
├── 00_需求输入/
├── 01_脚本/
├── 02_素材/
│   ├── 原始素材/
│   ├── 加工素材/
│   ├── 视觉预演/
│   ├── 音频/
│   └── 字幕/
├── 03_工程文件/
│   ├── <project-slug>/
│   ├── 剪辑工程/
│   └── 渲染输出/
└── 04_交付/
```

## README 建议字段

```md
# <project-slug>

- 客户：
- 关联品牌：
- 视频类型：长视频 / 短视频
- 项目主题：
- 当前状态：
- 主代码目录：
- 视觉预演目录：`02_素材/视觉预演/`
- 剪辑工程目录：
- 最后更新：
```

## 规则

1. `03_工程文件/<project-slug>/` 是唯一正式主代码目录。
2. 不再新增 `03_工程文件/代码工程/`。
3. `参考工程/` 先归档，不进入活跃结构。
4. 视觉方向不明确时，先在 `02_素材/视觉预演/` 产出 mood frame、key visual、UI scene still 或 storyboard frame，再进入代码实现。
5. 静态场景和过程导出放进 `03_工程文件/渲染输出/`。
6. 最终交付只进入 `04_交付/`。
