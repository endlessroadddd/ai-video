# 客户项目初始化模板

> 用于在仓库根目录下创建新的正式客户目录。

## 目录命名

```text
YYYYMMDD_客户名
```

示例：

```text
20260401_Lucius
20260407_OpenRouter
```

## 初始化目录

```text
YYYYMMDD_客户名/
├── README.md
├── PROGRESS.md
├── 00_客户素材/
├── 01_长视频项目/
└── 02_短视频项目/
```

## 创建顺序

1. 创建客户根目录
2. 创建 `README.md` 与 `PROGRESS.md`
3. 创建 `00_客户素材/`
4. 创建 `01_长视频项目/` 与 `02_短视频项目/`
5. 在 `README.md` 中写明关联品牌库

## 规则

1. 客户根目录不再保留 `01_脚本/`、`02_长视频/`、`03_短视频/` 作为正式入口。
2. 客户共享素材只放在 `00_客户素材/`。
3. 长视频与短视频必须进入各自的项目目录。
